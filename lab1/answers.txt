4)Что такое ядро ОС типа UNIX?
    Ядро - центральная часть операцонной системы, управляющая доступом к приложениям, файловой системе, внешним устройствам ввода-вывода.

5)Каким образом ОС типа UNIX различает пользователей системы?
        Как известно,в лиункс есть два типа пользователей:
            1.Обычные пользователи
            2.Суперпользователь
        Отличаются они тем, что у СП UID и GUID равны нулю и он имеет неограниченные права.
        UID - user ID
        GUI - group ID
        Итак, условно иерархию пользователей на UNIX-машине можно представить следующим образом:

            Суперпользователь - неограниченные права.
            Обычный пользователь - права с ограничениями, установленными для него суперпользователем.
            Специальный пользователь - права с ограничениями, установленными ему суперпользователем для работы с конкретным приложением.
            Псевдопользователь - нет никаких прав, он вообще не идентифицируется системой.

            Информация о соответствии пользователей,символьных имён, паролей и прочим приводится в следущих файлах:
                 /etc/passwd
                 /etc/group
                 /etc/shadow
                 /
            Каждая строка (учетная запись) в файле /etc/passwd описывает одного известного системе пользователя.
            user_01:x:169:10:Student:/home/user_01:/bin/sh
            1.Имя пользователя
            2.Пароль
            3.UID
            4.GUI
            5.Комментарий
            6.Начальный каталог(домашний)
            7.Начальная команда

        /etc/group соотносит числовые идентификаторы групп с символьными именами.
        1.Имя группы
        2.Пароль группы
        3.Идентификатор группы
        4.Список пользователей

        sambashare:x:135:patt,user3

         /etc/shadow  используют системы с теневым хранением паролей, где они вынесены из доступного всем пользователям на чтение файла /etc/passwd для повышения безопасности системы. Здесь (помимо собственно зашифрованных паролей) хранятся дополнительные ограничения, связанные с регистрационным именем и паролем пользователя. Доступ к этому файлу на чтение имеет только пользователь root, а работают с ним команды passwd и login.

         patt:$y$j9T$ldeYwaN2bOiYMhN.22BEC.$EbwiZrhbZfU8SDsWhk/JlCWXn0ulWOapb8sugoOKN26:20118:0:99999:7:::

         1.Имя пользователя
         2.Зашифрованный пароль
         3.Количество дней между 1 января 70-м и датой изменения пароля
         4.Минимальное количество дней между изменениями паролей
         5.Срок действия пароля пользователя
         6.За сколько дней система будет начинать предупреждать пользователя о необходимости изменения пароля.
         7.Сколько дней пользователь может не работать в системе, прежде чем его регистрационное имя будет заблокировано.
         8.Дата, после которой имя пользователя нельзя будет использовать в системе.

6)Когда заканчивается регистрация пользователя в системе?

    Регистрация пользователя в системе закаанчиваться тогда, когда root отключит учётную запись в соответсвии данными,указанными в /etc/shadow

7)Кто устанавливает идентификатор и пароль пользователя в системе?
    Суперпользователь root эти данный храняться в /etc/passwd  и /etc/shadow

8)есть ли различие между понятиями «идентификатор пользователя» и «имя
терминала пользователя»?
    Идентификатор пользователя - это уникальное число,присвоенное при создании и позволяющее однозначно идентифицировать пользователя
    Имя терминала - это название эмулятора терминала с которым пользователь работает в рамках данной сессии

9)Есть ли различие между понятиями «рабочая директория» и «домашняя директория»
для пользователя?
    Рабочая директория - это та директория, в которой пользователь находиться в данный момент.
    Рабочая директория - это директория, которая закреплена за пользователем при входе в систему, обычно это
    /home/имя_пользователя

34) К чему может привести применение команды cat к исполняемому файлу?

    Применение cat в формате cat <имя файла> привдёт к отображению содержимого файла.
    Само содержимое зависит от типа файла.


0 — STDIN (поток ввода)
1 — STDOUT (поток вывода)
2 — STDERR (поток ошибок
